# 17. Testing and tooling

Date: 2026-10-03 · Status: Accepted

## Context

Non-functional requirements: unit tests, pre-commit hooks (format, `go mod tidy`, fast tests),
and end-to-end tests in CI against HA in Docker. HA can be onboarded headlessly:
`POST /api/onboarding/users` returns an auth code, `POST /auth/token` exchanges it for a token, and
the WebSocket command `auth/long_lived_access_token` can mint a long-lived token.

## Decision

- **Unit tests:** pure Go. `go test -short` runs only these. The WebSocket client and the
  config-flow driver are tested against an in-process fake server. The client is consumed through
  interfaces.
- **Acceptance tests:** `terraform-plugin-testing` with `TF_ACC=1`, run with the OpenTofu binary.
  HA is started by **testcontainers-go**. A Go test helper onboards HA headlessly and mints a
  token. Every resource gets create, read, update, import, and destroy steps.
- **CI matrix:** the HA image tag is set to the oldest and newest release of the support window
  (ADR-0003).
- **pre-commit** (the `pre-commit` framework): gofumpt, `go mod tidy` with a diff check,
  golangci-lint, `go test -short`, and a docs check.
- **Docs:** generated by `tfplugindocs` from schema descriptions, `examples/`, and `templates/`.
  CI and pre-commit fail when `docs/` is stale.

## Consequences

Acceptance tests need Docker. They are skipped without `TF_ACC`, so contributors can run unit
tests anywhere.
